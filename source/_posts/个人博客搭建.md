在GitHub上搭建一个个人博客，作为笔记日志的存放。

## 环境

+ OS: windows10
+ Node: >=10.0.0
+ Git: >=2.17.1

## 工具/平台

``` shell
GitHub  -- 博客
Hexo    -- 博客框架
NexT    -- 博客主题
gitee   -- 图床
PicGo   -- 图片上传管理
Typora  -- 编辑器
```
<!-- more -->
## 步骤

### GitHub

1. 注册账号
   
2. 新建仓库
   名称格式：username.github.io
   这也是博客的访问地址。

   ![image-20200531202258405](https://gitee.com/GeoDaoyu/PicGo/raw/master/blog/image-20200530104727936.png)

### Hexo

1. 安装Hexo脚手架并创建项目

   ``` shell
   npm install hexo-cli -g
   hexo init blog
   cd blog
   npm intall
   hexo server
   ```

2. 编辑**站点配置文件**
   编辑根目录下` _config.yml`文件，包括Site、URL、Deployment等。
   
3. 常用命令

   ```shell
   hexo init [folder]               # 新建网站
   hexo new [layout] <title>        # 新建文章
   hexo generate                    # 生成静态文件
   hexo server                      # 启动服务
   hexo deploy                      # 部署网站
   hexo clean                       # 清除缓存文件和静态文件
   ```

4. 部署到GitHub
    站点配置文件的Deployment如下配置：
   
   ~~~ yaml
   # Deployment
   ## Docs: https://hexo.io/docs/deployment.html
   deploy:
     type: git
     repo: https://github.com/GeoDaoyu/GeoDaoyu.github.io.git
  branch: master
   ~~~
   
   命令行输入命令进行推送部署：
   
   ```shell
   hexo d
   ```
   
   

>注：如报错无法加载hexo.psl文件，修改windows的设置，允许powershell脚本在未签名的情况下运行即可。

### NexT

1. 下载并启用主题
   
   ``` shell
   cd blog
   git clone https://github.com/iissnan/hexo-theme-next themes/next
   ```
   
   打开**站点配置文件**， 找到 `theme` 字段，并将其值更改为 `next`。
   
   ``` yaml
   theme: next
   ```
   
2. 设定主题

   + 选择Scheme
   + 设置语音
   + 设置菜单
   + ......

### gitee

1. 注册账号
2. 新建仓库
   名称随意，仓库作为图床使用。
3. 获取token

### PicGo

1. 下载安装

2. 配置图床
   在**插件设置**中搜索gitee，然后下载安装。
   ![image-20200531202258405](https://gitee.com/GeoDaoyu/PicGo/raw/master/blog/image-20200531202258405.png)

   在**图床设置**中设置参数，

   ``` yaml
   owner: gitee的用户名
   repo: 项目名称
   path: 项目下的路径
   token: gitee的token
   message: 代码提交的说明，随意填写
   ```

   ![image-20200531202442036](https://gitee.com/GeoDaoyu/PicGo/raw/master/blog/image-20200531202442036.png)

### Typora

1. 下载安装

2. 配置图片上传
   ![image-20200531212036484](https://gitee.com/GeoDaoyu/PicGo/raw/master/blog/image-20200531212036484.png)

   复制一份到本地，然后手动点击上传的时候再上传。
